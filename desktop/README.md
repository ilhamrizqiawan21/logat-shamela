# Logat Syamilah Desktop

Desktop memakai build React yang sama dengan web dan menjalankan FastAPI sebagai backend lokal.

Development: `npm install`, lalu `npm run dev` dari folder ini.

Untuk installer Windows, buat backend terlebih dahulu dengan `pyinstaller --distpath backend-dist packaging/logat-server.spec`, sehingga folder `backend-dist` berisi `logat-server.exe`, lalu jalankan `npm run dist`.
